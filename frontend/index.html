About

AI-powered Content Transformation Platform — a multi-agent system that turns a single source document into multiple communication-ready formats, while keeping every output grounded in the original source.

How it works

🔎 Analyzer Agent

Reads the source content and extracts the key facts, statistics, entities, dates, problems, and recommendations into a structured understanding.

🧠 Planner Agent

Decides which output formats are needed and creates an execution plan for the rest of the pipeline.

🔀 Dynamic Router

Routes each request to only the specialized output agents that are actually required — nothing runs unnecessarily.

🤖 Output Agents

Specialized agents generate each requested format: Summary, LinkedIn Post, Twitter/X Thread, Advisory, Presentation, and Infographic.

🔍 Fact Checker

Verifies the generated content against the original source, reports a grounding score, and flags any claim that could not be fully verified.

The system transforms source material into communication-ready content while keeping outputs grounded in the provided source.
